# App Development Internship Projects

This repository contains the app development projects developed as part of my App Development Internship using HTML, CSS, and JavaScript.

## Projects

### 1. Flashcard Quiz App

Flashcard Quiz App is an interactive learning application designed to help users learn and revise information using digital flashcards. It includes features such as Show Answer, Next, Previous, Add, Edit, and Delete flashcards.

**Technologies Used:**

* HTML5
* CSS3
* JavaScript

### 2. Random Quote Generator

Random Quote Generator is a simple and interactive web application that displays random motivational quotes along with their authors. Users can generate a new quote using the New Quote button.

**Technologies Used:**

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the required project folder.
3. Open `index.html` in a web browser.
4. Explore the application.

## Purpose

These projects were developed to gain practical experience in application development, JavaScript functionality, responsive design, and creating interactive user interfaces.
